# CCS Connect

A polished React + TypeScript + Tailwind CSS experience that mirrors the requested CCS Connect ERP UI with a marketing-style landing page, role-aware login flow, and a premium dashboard shell.

## Features

- Responsive landing page with premium hero and feature cards
- Login experience with role preview and protected route flow
- Dashboard shell with KPI cards, trend visualizations, and order/inventory modules
- Reusable UI primitives and a component-driven structure

## Scripts

- npm run dev — start the Vite development server
- npm run build — create a production build
- npm run preview — preview the production build locally
